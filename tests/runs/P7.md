## Skill defects

### 1. Green-cast / coloured-reflection handling is inconsistent and can create a false "olive" (top defect)
- **`references/colour-analysis.md` §3** has a row for "Coloured wall or clothes near face → reshoot with neutral cover → Low". It also tells the model to run `palette_tools.py wb --white <paper hex>`. These conflict. A paper-based per-channel gain corrects the *light source*, but here the green came from a wall and a jumper reflecting onto the face from the side and below. The paper doesn't see that bounce in the same amount, so the correction is wrong. The file never says "don't run wb when the cast comes from reflections".
- **`scripts/palette_tools.py` `white_balance()`**: I tested it with a slightly green paper (`--white "#E8F0E2" --sample "#A8805F"`). It returned `"confidence": "medium"` and labelled the cast **"yellow/orange (warm bulb or golden hour)" AND "green"**. Two problems:
  - (a) The confidence is Medium, while the table says Low for coloured reflections.
  - (b) A yellow-green paper is reported as a warm-bulb cast, which could push the model to read the person as *less* warm after correction.

  **Fix:** add a `--reflection` flag (or a note in the output) that forces `confidence: low` and says "undertone from this photo is not usable; value/contrast only". Separate "green-yellow" from "yellow/orange" using the a* sign (a* < 0 with b* > 0 is foliage/green, not a warm bulb).
- **§6 Olive protocol** never warns that green casts (green walls, green clothing, foliage, fluorescent light) *imitate olive*. **Fix:** add "False olive: never conclude olive from a photo with a green cast. If the person self-describes olive and the photo has a green cast, the photo can neither confirm nor refute it; rely on draping and compliment history." Also cross-reference the existing "Fluorescent: olive misread" row.
- **§2 quality gate** says "Partial pass: use the good photos and lower confidence". It doesn't say which dimensions a cast-affected photo is still usable for. **Fix:** add "A hue cast spoils undertone (and partly chroma), but value and contrast can still be read at Medium."
